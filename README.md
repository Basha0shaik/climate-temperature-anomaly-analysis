# climate-temperature-anomaly-analysis

Climate temperature anomaly and decade-level trend analysis using Python, Xarray, NetCDF and Matplotlib.

*Project title*
Climate Temperature Anomaly & Decade Trend Analysis

*Objective*

Analyze historical temperature data and identify long-term climate patterns using temperature anomalies and decade-level aggregation.
Dataset
Monthly regional temperature data covering 1980–2020, stored in NetCDF format.

*Tools*

>Python
>Xarray
>Pandas
>Matplotlib
>NetCDF
>Google Colab

*Workflow*

NetCDF
   ↓
Dataset inspection
   ↓
Baseline calculation
   ↓
Temperature anomalies
   ↓
Decade aggregation
   ↓
Visualization
   ↓
ESG interpretation

*Key result*
Decade-level aggregation reduced short-term variability and made the long-term increase in temperature anomalies easier to interpret.
